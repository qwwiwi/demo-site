# demo-site – «Барн Модуль»

Одностраничный лендинг модульных домов в стиле барнхаус (Московская область). Демо для вебинара.

- `index.html`, `styles.css` – статичный сайт, шрифты Geist / Geist Mono (Google Fonts), SVG-иллюстрации инлайн.
- `server.js` – минимальный Node-сервер без зависимостей для деплоя (`npm start`, порт из `$PORT`, по умолчанию 3000).
- `DESIGN.md` – дизайн-система для любых материалов в этом стиле (сайты, слайды, баннеры).

Форма заявки ничего не отправляет на сервер – показывает благодарность в браузере.

Локально: `npm start` → http://localhost:3000
