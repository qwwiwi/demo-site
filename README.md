# demo-site – «Барн Модуль»

Одностраничный лендинг модульных домов в стиле барнхаус (Московская область). Демо для вебинара.

- `index.html`, `styles.css` – статичный сайт, шрифты Geist / Geist Mono (Google Fonts), SVG-иллюстрации инлайн.
- `server.js` – минимальный Node-сервер без зависимостей для деплоя (`npm start`, порт из `$PORT`, по умолчанию 3000).
- `DESIGN.md` – дизайн-система для любых материалов в этом стиле (сайты, слайды, баннеры).

Форма заявки ничего не отправляет на сервер – показывает благодарность в браузере.

Локально: `npm start` → http://localhost:3000

## SEO: как сделано

Блог (`/blog/`, 5 статей) оптимизирован по чек-листу движка [ai-native-seo](https://github.com/qwwiwi/ai-native-seo) и SEO-скиллов из его набора: `seo-autopilot`, `blitz-seo`, `blog-refresher`, `seo-title-optimization`. Код движка в репозиторий не копировался – применены только проверки и правила.

- **Тайтлы (seo-title-optimization):** главный запрос в начале, 40–60 символов до бренда, тайтл, H1, description и slug про одну тему; H1 статьи «модульный или каркасный» приведён к slug.
- **Структура (blog-refresher):** один H1, запрос в первом абзаце и в части H2, видимая дата «Обновлено: 22.10.2026», короткие абзацы.
- **Перелинковка (seo-autopilot / blitz-seo):** в каждой статье блок «Читайте также» на 4 соседние статьи + контекстные ссылки и ссылка на форму расчёта `/#calc`; без страниц-сирот.
- **Разметка:** JSON-LD `Article` + `FAQPage` (из блока «Частые вопросы») + `BreadcrumbList`, canonical, Open Graph и `twitter:card`.
- **Картинки:** обложка и 1–2 иллюстрации на статью (gpt-image-2, без текста и логотипов), WebP до 250 КБ, `width`/`height`, `loading="lazy"` кроме обложки, alt на русском с запросом; схема планировки – инлайн-SVG. Фото проектов конкурентов – с подписью и ссылкой на источник.
- **Индексация:** `sitemap.xml` с `image:image`, домен https://demo-site-f9f703.pipecore.io.
- **Правило движка:** никакой выдуманной статистики, цифры – ориентировочные диапазоны с оговоркой.
